瓦尔基里 V360 MERLIN 水冷屏控件（EXE 版）

程序
- 水冷屏自定义\dist\ValkyrieV360水冷屏控件.exe
- 当前 Windows 用户已配置登录自启动。登录后控件在后台运行，不显示控制台。
- 任务栏通知区显示控件图标；双击图标打开页面，右键可打开页面或退出后台服务。
- 双击 EXE 可打开控制页面；如果后台已经运行，只打开页面，不会再启动一个设备服务。
- 页面地址：http://127.0.0.1:8765/水冷控件简版.html
- 退出当前 Windows 登录会话后服务结束；下次登录时自动启动。

使用
1. 退出官方 Myth.Cool，避免同时占用水冷屏。
2. 在控制页选择本地视频。视频处理由后台 FFmpeg 子进程完成，不弹出命令窗口。
3. 设置方向、画面适配、亮度和写屏帧率（1–30 FPS，默认 10），点击「写入水冷屏」。视频会循环播放。
4. 点击「停止发送」后屏幕保留最后一帧。

通信与运行依赖
- 按原应用安装信息识别 MSDisplay 设备 VID/PID 345F:9132，控制通道为 HID feature report，视频通道为 interface 3 / bulk OUT 0x04。
- 随 EXE 内置 Myth.Cool 安装包的 64 位 libusb0.dll、MS USB Display 驱动文件及 FFmpeg 运行库；本机不需要另装 Python 或配置 FFmpeg PATH。
- 视频输出 320×240；帧率可设为 1–30 FPS，10 FPS 与设备每帧 100 ms 触发间隔匹配。方向、适配和亮度在写入前处理为视频画面。
- 仅监听本机 127.0.0.1:8765；后台日志位于 %LOCALAPPDATA%\ValkyrieV360\control.log。

管理
- 移除登录自启：在命令提示符运行："水冷屏自定义\dist\ValkyrieV360水冷屏控件.exe" --remove-startup
- 重新注册自启：运行同一 EXE 并带参数 --install-startup。
- 控件已在 V360 MERLIN 实机上确认视频写入。若连接失败，请确保 USB 数据线接入主板 USB 2.0 插针、Myth.Cool 已退出且原驱动已安装。USB 数据线与水冷泵供电线用途不同。
